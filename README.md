# Ex. No.  - SIMULATION ANALYSIS ON SLIDER CRANK MECHANISM

## DATE: 12-03-2026

## AIM:
###   To determine & simulate the displacement & velocity analysis for the given slider crank mechanism. 
###   An engine mechanism is shown. The Crank CB = 200mm and the connecting rod BA = 600mm. In the position shown, the crankshaft has a speed of 50 rad/s and an angular acceleration of 800 rad/s2


## REQUIREMENTS:
###   ●	Mech Analyzer software.
###   ●	Processor: Minimum 1.5 GHz
###   ●	RAM: Minimum 512 MB
###   ●	Operating System: Windows XP, Windows Vista, Windows 7, Windows 8 or higher.
###   ●	Dependencies: Microsoft .Net 2.0 framework
###   ●	Mini Drafter.
###   ●	Geometry instruments.

## PROCEDURE:
###  Step 1: Draw the reference line

Draw a horizontal straight line using a ruler.

Mark a point C anywhere on this horizontal line.

This line will act as the base/reference line.

### Step 2: Draw line CB

At point C, use a protractor.

Measure an angle of 120° from the horizontal line.

Draw a line from C at 120°.

On this line measure 20 mm and mark point B.

Now CB = 20 mm.

### Step 3: Draw arc to locate point A

Take a compass.

Set the radius to 60 mm.

Keep the compass needle at B (center).

Draw an arc that cuts the horizontal line.

The point where the arc cuts the horizontal line is A.

### Step 4: Join BA

Use a ruler and join point B to point A.

Now the configuration diagram C–B–A is completed
